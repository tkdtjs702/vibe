## 지표 독립 계산 대조

환경은 demo fixture이며 누적 수치(`salesAcc`, `audiAcc`)는 더하지 않았다.

| 날짜 | 손계산 매출 | 실제 | 손계산 관객 | 실제 |
| --- | ---: | ---: | ---: | ---: |
| 2026-09-07 | 5,200,000 + 3,800,000 + 2,400,000 = 11,400,000원 | 11,400,000원 | 510 + 365 + 228 = 1,103명 | 1,103명 |
| 2026-09-08 | 5,380,000 + 3,890,000 + 2,355,000 = 11,625,000원 | 11,625,000원 | 528 + 374 + 224 = 1,126명 | 1,126명 |

두 날짜 관객 합계는 독립 계산과 실제 모두 2,229명이다. `movieCd=20260001`의 매출은 5,200,000 + 5,380,000 = 10,580,000원이며 실제 Top 영화 집계도 10,580,000원이다.
